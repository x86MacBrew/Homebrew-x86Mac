# Contributing to x86MacBrew

x86MacBrew is an independent continuation of Homebrew-compatible tooling for
Intel `x86_64` Macs. It is **not** affiliated with, endorsed by, or supported by
the Homebrew project. Please do not describe it as official Homebrew anywhere,
including in issues and pull requests.

## Before you start

Read [docs/formula-scope-policy.md](docs/formula-scope-policy.md). Most rejected
proposals are out of scope rather than defective.

Run the validator before opening a pull request:

```sh
scripts/check-repository.sh
```

It checks the support policy and release manifest schema, every formula's class
name, HTTPS URLs, checksum format and tap-local dependencies, that published
formulae match a recorded release, and shell syntax. CI runs the same script,
so a local pass is the fastest way to avoid a failed check.

## What a pull request may change

| Change | Accepted from | Notes |
| --- | --- | --- |
| Documentation, typos, clarifications | Anyone | |
| Diagnostic (`bin/x86macbrew-doctor`) improvements | Anyone | Must keep working when `config/support.yml` is absent |
| New source-build candidate formula | Anyone | Must build and `brew test` on Intel macOS 15; record it in [docs/package-status.md](docs/package-status.md) |
| Validator rules | Anyone | Add a failing case demonstrating the rule catches what it claims |
| Bottle entries in `config/release-manifest.yml` | Maintainers only | Requires the full evidence set in [docs/release-policy.md](docs/release-policy.md) |
| `Formula/x86macbrew-doctor.rb` | Maintainers only | Generated by `scripts/render-doctor-formula.sh` after a real release; never hand-edited |

## Adding a source-build candidate

A source-build candidate is a formula proven to compile and test on Intel
macOS 15. It is **not** a supported package — that requires a published bottle.

1. Add the formula under `Formula/<first-letter>/<name>.rb`.
2. Declare tap-local dependencies as `x86macbrew/x86mac/<name>` and add them to
   this tap too; the validator rejects dependencies it cannot resolve.
3. Build and test on an Intel Mac running macOS 15:
   ```sh
   brew install --build-bottle x86macbrew/x86mac/<name>
   brew test x86macbrew/x86mac/<name>
   ```
4. Record the outcome honestly in [docs/package-status.md](docs/package-status.md),
   including anything that did not fully work.
5. Run `scripts/check-repository.sh`.

Do not add a bottle block or a manifest entry. Bottle promotion is a maintainer
action with its own evidence requirements.

## Reporting a host that fails the diagnostic

Include the full output of:

```sh
x86macbrew-doctor --json
```

That output contains only architecture, macOS major version, Homebrew prefix,
and CPU feature flags.
