# Governance and sustainability

## Repository owners

- `x86macbrew/brew`: Compatibility Client Team
- `x86macbrew/homebrew-core`: Formula Catalog Team
- `x86macbrew/homebrew-x86mac`: Distribution Tap Team

Each repository must have at least two active maintainers and a named security contact.

## Triage policy

- Security issues: acknowledge within 48 hours.
- Release-blocking regressions: acknowledge within 72 hours.
- Standard issues: acknowledge within 7 days.

Issue labels should classify impact (`security`, `release-blocker`, `support`, `out-of-scope`).

## Lifecycle policy

- Current guaranteed target: Intel `x86_64` macOS 15.
- New macOS major support requires explicit announcement and updated support policy.
- Deprecating a supported macOS major requires at least one announced maintenance release window.

## Project commitment

This project provides best-effort continuation with explicit support boundaries. Users should treat the release manifest as the source of truth for supported formulae and versions.
